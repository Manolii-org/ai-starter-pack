# Native owning recipe

The Pack's read-only native job executes the existing owner recipe at the exact
native-event source head and integrated base. It classifies before installing
optional build dependencies, preserves the configured commands and budgets,
and runs with no deployment credentials, production environment or review action.

One job produces a small public execution summary. It uploads neither the raw
private readiness receipt nor cache keys, dependency state or environment values.
The summary distinguishes unselected work, failure, executed selected checks and
execution of every configured check. A job/check success for unselected work is
not qualification evidence. Individual test logs remain necessary to assess
coverage and skipped work; this wrapper does not manufacture test counts.

The summary grants no independent review, release admission, native human
approval, mutation credential or production authority. Receivers must still bind
the reviewed native workflow/job and immutable subject through the owning policy.
Existing combined-base checks, names/providers and installed controls remain.

This controller is Pack-local. It is excluded from Copier consumers and refuses
other repositories before reading their recipe or private state. Other owners
retain their own qualification, credential and evidence transports.

The native job provides an actual supported Linux qualification route when a
development host cannot execute namespaces or finish the normal recipe. It
does not waive a prerequisite or turn a failed local attempt into a pass.
Temporary overlap with existing source CI is recorded qualification cost, not a
claim of invoice savings.
